# Physical preparation journal review

The SQLite journal reserves the exact original Compile or Launch input and its
complete Ready allowance before granting preparation. A committed transition
returns the sole live claim. Independent connections serialize through the same
writer lock; recovered Preparing rows return Unknown and never another claim.
Historical Ready survives uncertainty and witnessed cleanup. Closing an endpoint,
sealing admission and observing resource cleanup are separate operations.

Every row operation uses named Parrot/sqlc queries. Runtime SQL literals are
limited to schema installation, transactions and PRAGMAs. While generating the
bindings, an invalid SQL query exposed a pinned Parrot CLI defect: it printed an
error but exited zero. The wrapper now requires both process success and the
post-generation success marker. Three isolated controls cover a printed error
with exit zero, a nonzero exit despite success text, and successful generation.
The real invalid-query run now exits one; valid regeneration exits zero.

## Review and verification

The independent review found no reachable implementation defect. Its one
coverage finding was valid: row exhaustion masked the byte-retention test.
The revised fixture allows two rows and proves each invocation fits alone, while
their combined lifetime reservations do not. A compiling mutation excluding
Released rows from byte accounting now admits the second request and fails the
intended Capacity assertion. Production source was restored exactly.

A separate compiling mutation that reissued a claim from retained evidence fails
the expected Existing Unknown assertion. The SQLite controls also exercise a
real deferred-foreign-key COMMIT failure, suppressed writes, independent opens,
identity substitutions, capacity, sealing and recovery. Discarding a completed
Ready call's return value tests lost acknowledgement recovery; it is not a
transport interruption or a power-loss experiment.

Root's final independent gate passed all 176 executor tests without reported
skips in 93.505 seconds, with exit zero. The three generator-wrapper controls
also passed. All frozen source and generated files matched before and after.
A subsequent removal of one blank line at the SQL file's end fixed the whitespace
gate; regeneration succeeded and every generated byte remained unchanged.
Formatting, lint and documentation checks passed in the component tree.

## Limits

The journal bounds logical retained input and Ready bytes, not SQLite page/WAL
size, resident memory or hard elapsed time. The trusted physical service must
reserve final outer outcome capacity before effects and re-vet Compile or admit
actual retained successful Compile evidence before Launch. Gleam values are
copyable; the trusted adapter must consume a returned Claim at most once.
Historical Ready cannot reconstruct a live listener, token or preparation owner.

Physical assembly, terminal custody, native retirement and separate-host
acceptance remain outstanding. These component checks are not a final Linux
signoff or proof that the shipped daemon supports remote workspaces.
