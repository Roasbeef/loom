# Distributed runtime integration with current main

This review covers the merge of main `7a9adf1e83350bf89cddd1dac98ee69d16f22c02`
into integration parent `eb68c9b66404a2b08b59f0806c1a4a26e6c7cf72` for
[PR #819](https://github.com/Roasbeef/loom/pull/819). It validates the merge
boundaries; it does not establish complete distributed-runtime acceptance.

## Resolutions

Main already published catalogue schema version 5 for session subtitles. The
unreleased remote workspace binding migration now uses version 6. Existing
version-5 databases retain their subtitle and default workspace; older versions
apply both migrations in order. No compatibility path was added for unreleased
feature-branch databases that used version 5 differently. The new real migration
fixture checks retained data, local binding and committed user_version.

Catalogue SQL and generated decoders retain both workspace binding and subtitle.
The scoped Parrot/sqlc generator reproduced the exact generated bytes; its three
failure-reporting regression controls passed. Session JSON includes the subtitle
and either the local workspace or complete registered binding.

Satellite admission retains managed provenance validation before tally or worker
creation, alongside main's call-record ledger. A combined regression sends two
invalid managed-origin calls and a valid owner callback. Both refusals appear as
failed invalid_origin records; neither spends a native ordinal.

Main's new scan_entry_heads storage operation is forwarded through the owner's
erased storage adapter. Client fixtures were updated to supply subtitle, typed
workspace bindings and workspace authority without changing their assertions.
The handoff retains main's concise baseline and separates the unmerged distributed
work. Architecture citations were checked against the combined source.

must serialize their shared binaries prerequisite.

The client's skips cover the unavailable Linux /proc witness, shipped-server
fixtures requiring LOOM_BOOTSTRAP_E2E_SERVER, and unavailable rust-analyzer.
Its log also contains pre-existing advisor fixture panics from receiving on a
subject owned by another process, alongside intentional supervisor termination
reports. The EUnit exit is successful; it is not evidence that those peer panics
were repaired by this merge. Final Linux/shipped acceptance remains required.

Earlier attempts are retained: the unseeded code-mode gate skipped eight tests;
the seed fetch failed in the restricted environment before an authorized fetch
succeeded; client compilation exposed obsolete constructors before their repairs.
No failing test was deleted or changed into a skip. This component milestone is
not the full repository gate, hosted signoff or separate-host acceptance.
