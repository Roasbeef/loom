Loom msgpack golden fixtures (ADR-003)

Each .bin file holds exactly one msgpack value in the canonical
(smallest) encoding produced by core/msgpack (Gleam side of the
framing protocol). Conformance requirement for every implementation:
encoding the described value must produce the file's bytes exactly,
and decoding the file's bytes must produce the described value and
consume the whole file.

Mirrored in packages/core/test/core/msgpack_test.gleam (golden_*
tests). Adding or changing a fixture requires updating that test
suite, the Go helper's suite, and ADR-003.
